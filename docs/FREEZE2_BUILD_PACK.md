## 1. Addition A — Daily Observation Ledger (build first)

A reusable observed-data export, generated by a repo script from the repo
pipeline's harmonized data. One row per date × satellite selection actually used:

Fields: `date, satellite_selection, recorded_cell_days, coverage_status, product,
comparison_inclusion`
- satellite_selection: named set, e.g. "Terra+Aqua", "Terra+Aqua+Suomi NPP+NOAA-20",
  "all included".
- coverage_status: one of `verified` / `partial` / `unverified` (2026-11-15 =
  unverified, recorded_cell_days = null, never 0).
- product: SP or NRT per season rules (2001–2025 SP; 2026 NRT).
- comparison_inclusion: which preset(s)/pair(s) the row feeds, or "none".
Metadata block: grid (~1 km cells), confidence rules (VIIRS nominal+high; MODIS
≥ 50), bbox (73.8, 27.6, 77.6, 32.6 — a rectangle, not an admin boundary), source
(FIRMS), cutoff (verified through 2026-11-14), dataset totals (1,601,380
retrieved / 1,482,211 retained).
Deliverables: downloadable CSV + the JSON the page loads. Framing (binding):
this is an observed-data ledger, a partial response to the brief — never call it
a harmonized record, never stitch pairs into a continuous series.

daytime detections only (daynight = D), per season: median acquisition time
