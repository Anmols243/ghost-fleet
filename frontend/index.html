APP. B / SYSTEM

Appendix B: The system behind the audit

Punjab-Haryana reference only; not recomputed for the selected region.

  1. FIRMS area API
  2. Standardize
  3. Harmonize to ~1 km cell-days
  4. Audit decomposition (W = U + C)
  5. Frozen audit.json
  6. This page

Each step links to its source file. Counts under the steps render from audit.json.

Retrieval
1,601,380 detections retrieved; 1,482,211 retained after confidence rules (VIIRS nominal + high; MODIS confidence ≥ 50). 26 seasons, 2001–2026.
Access rules handled
FIRMS area API in 5-day chunks; archive (SP) products for 2001–2025, near-real-time (NRT) for 2026.
Harmonization
Detections grouped into ~1 km cell-days by union — a cell-day counts once no matter how many satellites saw it. FRP is never summed across sensors.
Freeze
audit.json sha256 faee77abdc0570326ebe43567cbb1ead19d184646565945a0cd460faf44555ae — frozen; comparison numbers render from that file. Optional appendices use separately sourced files.
Verification
An independent re-aggregation from the raw archive reproduced all 9,568 daily counts exactly. 105 automated tests (45 pipeline, 60 frontend) cover the decomposition, the downloads, and malformed-data behaviour.
Stack
Python pipeline (pandas); this page is vanilla JS + inline SVG with zero external requests and no backend.

Reproduce it

From a clone of the repository. Fetching needs a FIRMS map key in backend/.env (see backend/.env.example).

cd backend
pip install -r requirements.txt
python scripts/fetch_firms.py
python scripts/harmonize.py
python scripts/audit.py        # writes frontend/audit.json
python -m pytest -q

Actual-fire change: not measured
